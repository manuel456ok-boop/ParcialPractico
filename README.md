# ParcialPractico

cree un sistema de gestión de inventario en  el lenguaje de C# que solicita al usuario los datos de dos productos ( en este caso uno electrónico y uno de alimento), los almacena en objetos de clases que heredan de una clase base Producto, y luego muestra la información de cada uno junto con su impuesto calculado: 18% para electrónicos y 8% para alimentos. (las capturas de pantalla estaran en el documento de word.)
